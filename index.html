Documentação oficial · v0.1

O Sart é uma linguagem de programação interpretada, de extensão .Sart, criada com foco em texto, decisões, variáveis e desenhos. Sua proposta é oferecer uma sintaxe própria, original e independente, sem copiar estruturas de linguagens consagradas como Python, JavaScript ou C. Cada comando tem forma e nome próprios, o que dá à linguagem identidade clara e distinta de qualquer outra existente.

A estrutura de um arquivo Sart consiste em uma sequência de comandos escritos linha a linha. O arquivo é encerrado por um símbolo próprio, o 《, que fica sozinho em uma linha, sempre no final do arquivo, precedido por duas linhas em branco. Esse símbolo nunca aparece no começo de uma linha, apenas como marcador de fim.

As importações podem ocorrer de duas formas. A primeira é a importação de texto, feita por meio do comando //import = <text>. A segunda é a importação de bibliotecas, feita por meio do comando Import, seguido do nome da biblioteca. O ponto faz parte do nome da biblioteca, e não funciona como separador de pacotes.

A impressão na tela é feita por meio do comando /Class/text, seguido do texto entre aspas. Esse comando já imprime diretamente, sem necessidade de chamada adicional, e é o principal meio de saída de texto da linguagem.

As variáveis armazenam valores e são declaradas por meio do operador />. A atribuição aceita tanto um número direto quanto um texto. Não há necessidade de declarar tipo previamente: a variável assume o valor que lhe for atribuído. Declarações de variável não utilizam ponto e vírgula.

A leitura de entrada do usuário é feita por meio do comando #input_user. Esse comando aparece sozinho, sem parâmetros, e o valor digitado pelo usuário entra diretamente na variável que está recebendo a atribuição por meio do operador />.

A estrutura condicional é aberta pelo comando Alt, que recebe uma condição e termina com ponto e vírgula. O bloco seguinte é executado caso a condição seja verdadeira. O comando Shit: marca o senão, e o bloco posterior a ele é executado caso a condição seja falsa.

O ponto e vírgula na Sart possui uma função única: marcar uma condição ou um valor. Ele nunca aparece em declaração de variável, nunca aparece sozinho em uma linha e nunca aparece duas vezes na mesma linha.

A Sart possui uma biblioteca oficial de desenho chamada Pen.draw, importada pelo comando Import Pen.draw. Essa biblioteca oferece comandos como Pen.start, que liga a caneta; Drawforward.pen, que desenha para frente e recebe como parâmetro a largura da linha; e Pen.up, Pen.down, Pen.right e Pen.left, que desenham, respectivamente, para cima, para baixo, para a direita e para a esquerda. O comando Pen.stop não existe na linguagem.

A linguagem é interpretada, o que significa que o código-fonte é lido e executado linha a linha, sem etapa prévia de tradução. Isso dá à Sart um caráter mais direto e experimental, adequado a scripts, protótipos e estudos de design de linguagens.

Diversos pontos da linguagem ainda não foram definidos formalmente. Entre eles estão: a existência de loops, a definição de funções pelo usuário, a presença de operadores aritméticos além do operador de comparação, a existência de outros operadores de comparação além do maior que, o suporte a listas ou arrays, a forma de salvar arquivos, a forma de importar código de outros arquivos .Sart e o comando de saída do programa.

Mesmo com essas definições em aberto, a Sart já possui identidade consolidada, com sintaxe própria, regras próprias e foco próprio. É uma linguagem pensada para quem quer programar com foco em texto e desenho, com comandos claros e com uma estética que remete a linguagens experimentais de verdade.

Sart is an interpreted programming language, with the .Sart extension, created with a focus on text, decisions, variables, and drawings. Its aim is to offer an original and independent syntax, without copying structures from established languages like Python, JavaScript, or C. Each command has its own form and name, giving the language a clear and distinct identity from any other.

The structure of a Sart file consists of a sequence of commands written line by line. The file is closed by its own symbol, 《, which stands alone on a line, always at the end of the file, preceded by two blank lines. This symbol never appears at the beginning of a line, only as an end marker.

Imports can happen in two ways. The first is text import, done through the //import = <text> command. The second is library import, done through the Import command, followed by the library name. The dot is part of the library name and does not work as a package separator.

Printing to the screen is done using the /Class/text command, followed by the text in quotation marks. This command prints directly, without needing an additional call, and it's the language's main way of outputting text.

Variables store values and are declared using the /> operator. Assignment accepts both a direct number and a text. There is no need to declare the type beforehand: the variable assumes the value assigned to it. Variable declarations do not use a semicolon.

User input is read through the #input_user command. This command stands alone, without parameters, and the value typed by the user goes directly into the variable receiving the assignment through the /> operator.

The conditional structure is opened by the Alt command, which receives a condition and ends with a semicolon. The following block is executed if the condition is true. The Shit: command marks the else, and the block after it is executed if the condition is false.

The semicolon in Sart has a single function: marking a condition or a value. It never appears in a variable declaration, never appears alone on a line, and never appears twice on the same line.

Sart has an official drawing library called Pen.draw, imported by the Import Pen.draw command. This library offers commands such as Pen.start, which turns on the pen; Drawforward.pen, which draws forward and receives the line width as a parameter; and Pen.up, Pen.down, Pen.right, and Pen.left, which draw up, down, right, and left, respectively. The Pen.stop command does not exist in the language.

The language is interpreted, meaning the source code is read and executed line by line, without a prior translation step. This gives Sart a more direct and experimental character, suited to scripts, prototypes, and language design studies.

Several aspects of the language have not yet been formally defined. Among them are: the existence of loops, user-defined functions, the presence of arithmetic operators besides the comparison operator, the existence of other comparison operators besides greater than, support for lists or arrays, the way to save files, the way to import code from other .Sart files, and the program's exit command.

Even with these open definitions, Sart already has a consolidated identity, with its own syntax, rules, and focus. It's a language designed for those who want to program with a focus on text and drawing, with clear commands and an aesthetic reminiscent of real experimental languages.
